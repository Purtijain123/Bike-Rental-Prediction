# Bike-Rental-Prediction
# 🚲 Hourly Bike Rental Demand Prediction
An end-to-end machine learning pipeline that predicts hourly bike-sharing demand (cnt) using historical usage, temporal patterns, and meteorological data. The project implements rigorous data validation, exploratory data analysis (EDA), domain-specific feature engineering, time-series cross-validation, and hyperparameter tuning across six regression algorithms.
